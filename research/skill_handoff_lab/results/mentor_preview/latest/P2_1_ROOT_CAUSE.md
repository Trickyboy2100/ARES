# 新增真实规划根因

旧0/6候选敏感性、114mm Groove统一几何冲突、P2.1全部负结果保持冻结。

Cabinet两个终态进入真实cuRobo后共同失败。完整world底盘代理与起点约41mm重叠；独立FK验证复现，并非驱动失败。该代理原为filter_owned、未测量CAD，不能用于声称真实机器人碰撞。

另外，附着物的link6 AABB+覆盖球模型在Cabinet目标与右门框重叠。预先固定35/20/15mm分辨率检查仍有9.75/7.73/7.00mm穿透，限制部件attached_object。原CPU OBB端点合法不能直接升级为cuRobo合法。仅隔离Cabinet的检查明确为诊断，没有删障碍修改正式世界或生成成功标签。

优先核实测量底盘、TCP—物体姿态与保守附着包络，再定义新的物理合理场景；扩大GPU或先训RL不能解决统一几何冲突。新Groove物理验收NOT_TESTED。
