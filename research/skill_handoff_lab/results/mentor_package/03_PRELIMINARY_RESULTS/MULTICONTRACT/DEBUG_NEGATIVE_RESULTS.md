# 必须保留的调试负结果

v11–v14多场景版本发现墙体在env局部坐标又加了一次env origin，导致实物墙体错位、最大约5.30m。这些成功是无效多场景调试数据，不能作为物理任务结果。旧3c20dcd单宽柜口墙体在clone前构建，不存在这个新增重复origin问题；旧结果不能因此被覆盖。

v15修复局部坐标，实际USD BBox逐墙核验误差<0.1mm。测得T2原90°入口与不旋转夹持姿态使腕/前臂进入侧壁；v16扩大口宽仍有过大接触，v17检查真实CAD包络后仍有前臂侧壁接触118–139N/约1–2mm凸包重叠。均保留失败，不通过删网格或改真实限位解决。

v18/v5任务修正为−45°真实入口与−45°合法持物Preplace，保持BODY安装标定和软限位。训练前32/32名义预检成功，6410个真实物理采样的工位/非相邻右臂自碰撞、工作空间与软限位检查均通过；最大连杆FK与PhysX位置差约1.3µm。该预检非RL性能结果。

源USD的CollisionAPI附在Xform容器而非实际Mesh，是需明确修复的schema疑点，不把它直接解释为全部旧碰撞都无效。研究层独立新USD将API落实至7个臂Mesh；原始USD保留。FCL审计也修正了Convex面朝向及多出Robot根刚体导致的索引误差，这些审计代码错误不是机器人物理失败。

所有版本源、参数、物理日志与原始状态在raw/debug中保留或在manifest引用；训练数据只采用预声明v5/v19，不混入调试数据。
