# EXP-002｜接触阶段合法动作权限与执行效果可观测性

**初始状态：QUEUED；阶段S3；科学依赖EXP-001。**
允许EXP-001期间先行做低成本设计，不能未经强基线证明就刷大训练。

## 假设

与预先选择抓持角/接近距离相比，在插入或工具接触形成后，
少量合法侧向/姿态/推进（必要时有界撤回）参数能产生实际可测的
纠偏、减少停滞，在完整任务中救回强名义不能完成的情况。
有效反馈包含执行后物体相对运动、夹持/接触代理和预算使用；
应验证哪些信息不只是已观测状态的冗余派生量。

## 任务设计

- 优先 PlugCharger 原生物理与200步，定义接近/初次接触/停滞等
  可测物理事件；可依据强基线失败机制换成另一种实际接触操作。
- 仅选择2–3个先通过手工配对证明合法的参数；参数边界从机器人
  执行能力和接触几何推导，而非从需要多少成功率逆向挑数值。
- action requested → projected/clipped → actual TCP/tool motion →
  target relative movement/contact → physical suffix outcome 全链记账。
- 对 **相同初态、同动作重复**估计随机性；对 **相同前段真实状态、
  不同后段动作**做因果对照。可用完整可复现状态作为研究探针，
  但训练/最终评价仍需全任务真实闭环；不得依赖理想瞬移完成前段。
- 对state-only upper bound和能部署的带噪观测分别量化反馈信息；
  若用真实仿真接触力，只能称接触代理、不能称已标定力传感器。

## 强基线与反证

同权限手工法、增益调好的几何反馈、replan/CEM/短时MPC应能使用
这组参数。若强规则即可可靠修复，则把其当基线并重新判断是否
还存在有学习意义的变化（摩擦、工具相对误差、目标等）。
**不通过旧单次失败案例强制选择“最优”新参数。**

## 应交

一次真正的物理动作权威性矩阵；有改善及退化的完整episode casewise
表、动作有效比例、实际效果连续曲线；冻结的合法执行/观测API与最强
规则基线。EXP-003只有在可学的真实控制权存在后才是划算的工作。
