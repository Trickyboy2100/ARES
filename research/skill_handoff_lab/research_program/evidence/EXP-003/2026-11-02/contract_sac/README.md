# 共享执行修复、真实两边界 SAC 与机制反证

入口：[交互审查页](REVIEW.html) · [同初态 RAW/英文视频与逐帧曲线](video_stroke/SYNC_VIEWER.html) · [原始数据 SHA 清单](RAW_MANIFEST.json)。独立算法增益 **UNVERIFIED**。继承14665cb、成熟SAC/STAP/log-Q、Pyramid36/36；未打开封存测试，ARES-R无修改。本轮全部物理来自公开ManiSkill，本地单3080、网络/串口隔离。不是现场机器人证据。

## 真正建立的认识

1. **计划正确不等于物理到位。** 共同执行器用0.01 screw积分，读实际规划末点FK，>2mm或0.02rad时调用原生qpos规划，完整native时间执行并最多等待4步。pilot计划FK中位0.755mm、最大1.432mm；实际末点仍最大8.124mm，23个已完成动作有8个超4mm。4mm是诊断/重试触发，绝非已保证的安全到位合同。原生接触力、跟踪误差和预算必须分开测。所有比较使用同执行器；不改成功阈值、不跳物理步。可选修正/失败都保留。
2. **3/8→6/8不是反馈信息增益。** 完整2×2消融：旧29cm stroke cap，无/有接触后重算均3/8；36cm cap，无/有重算均6/8。8组直到HOOK物理状态完全相同。救回由初始几何已能给出的321mm stroke解释；原.29截断是不必要权限限制。新训练和全部对照共享.36合法上限，明确区别旧版本，不把权限扩大计为RL。视频示例606.5→583.5mm，原生600mm判据不变。
3. **短暂稳定抓持不保证后续运输稳定。** 对齐已验证PICK_TOOL边界、TCP相对工具变换、首次>0.5N工具/工件接触、实际到位与预算；新35mm抓持的重载在首次接触前仍有6.32–7.97°漂移。旧10°级漂移以LIFT结束作替代边界，不能和新稳定边界混为同一测量。力100Hz，物体姿态20Hz；不伪称有100Hz姿态因果时序。
4. **当前第二参数机会薄弱。** 新4场景×3抓点×3钩入高度36物理条，固定70/105mm与已测oracle均3/4；相同前段后改高度未改变二值成败。后继加速度3/4.5/6的36条，降低加速度没有救回，反而出现1次预算退化。拓展拉动方向2/9→1/9；夹爪翻转自动选点4条及固定抓点12条均未救回两个共同失败。以上仅限所测条件，不否定其他跨技能适应机会，不扩大无信息训练。
5. **主动探测了第二任务，但没有伪造强基线。** 原生PokeCube-v1 /50步，PickPeg→PokeCube。4条先因抓持稳定/后段预算失败；直接接近4条开始移动工件，却引入另一初态抓取失败，仍0/4。原生工件距goal<50mm且robot静止判据未改。当前控制器未达到可信强基线；不得用它训练后声称RL击败强控制。

## 真正的普通 RL 已接通，但尚非“充分收敛”

物理生成器在两处真实技能决策暂停；同一环境、连续状态，无中间reset或物体设置。stage0合法抓点35–105mm；stage1合法hook高度26–38mm。45维当前状态含实际附着、工具/工件状态、已知密度与剩余预算；所有方法同信息。稀疏终端native成功，有限100步、gamma=1、预算入状态：这是普通未折扣SMDP，不是新算法。保留duration_steps，不能把每个物理步误数为RL决策。物理RNG与SAC采样RNG隔离。

复用critic LayerNorm SAC、128×128网络、lr3e-4、alpha.02、batch64、UTD2；没有新网络机制。第一尝试67完整回合/133转移，TOPP候选异常使当时内存actor未保存；保留全部67物理轨迹和错误，不能假称恢复了权重。后来精确捕获该规划候选错误，133条真实转移warmstart重新训练。SAC256：128回合/256决策/384更新；SAC512：256回合/512决策/896更新/959.8秒（模型learn循环计时，不含所有环境创建/评估开销）。中断审查时保留287完整回合、575已完成决策、1022更新、76步部分轨迹及模型/BUFFER。1个训练seed，不能宣称收敛或泛化论文结论。

独立回放审计：SAC512缓存645条=先前67+当前256回合，obs/nextobs/action/reward/done逐项与物理证据一致，最大误差0；322非终端+323终端，不跨reset bootstrap。模型比较器共享这323条真实物理数据，分别训练技能Q、SkillResult动力学、监督终端评分和真实后继状态上的名义后续价值（共10000更新）。STAP式采用log-Q组合与11×11候选，第一次132Q查询、后验阶段11；它是明确范围的同任务算法核基线，不冒充官方全复现。后续价值是ViSkill/SeqDex/Foresight思想对照，非那些算法的完整复现。不同优化/规划成本公开，不宣称完全计算等预算。

## 实际到位修正追加闭环

发现4–8mm实测残差后，本轮又实际跑了16条配对：相同条件下，TRANSFER后增加一次从真实关节状态出发的qpos重规划，仍完整原生时间与100步限制。**6/8→6/8，0救回0退化**；8条微小修正仅1–2控制步，实测位置误差4.72–9.78mm，并没有验证实际到位。这说明重新做一次精确IK不是跟踪/接触问题的充分修复。两个重载35mm失败均预算耗尽；一个native成功的回合同时记录Horizon异常，按最终原生成功评分，二者不混淆。该可选干预保留为负结果，不升格默认。详细原生路径与起止步见analysis/ARRIVAL_INTERVENTION.json。8对在干预前物理记录逐项完全相同。另核对早期共同控制器整段重复：7/8完整100步逐项一致；745010重载35mm在step73后出现不同规划动作，仍均失败，最大关节差0.157rad；不能声称全部重跑字节确定，具体见FINAL_REGRESSION.json。
