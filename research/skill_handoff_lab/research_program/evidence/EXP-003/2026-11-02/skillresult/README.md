## 这轮真正新增了什么

1. 三个严格同物理前段的STAP退化不是同一种故障：钩入耗尽预算；进入新增目标范围但原生成功失败；原生成功但43.3mm超出40mm目标合同。后验Q全很低，却仍强制改参；前验预测序列却接近1。完整Q曲线、候选时长、真实动作及状态误差见[机理核查](REGRESSION_MECHANISM.md)。STAP自带SCOD/风险规划已经覆盖“不确定性处理”思想，不能据此主张原创。
2. 按STATE运行96条新初态干预，49条成功；16个场景×目标条件中固定100/−65成功8个，六组实际参数的事后最优也只成功9个。**所测面板相对固定策略的剩余上限仅1/16**，不是整个任务动作空间的理论上限。未观察到严格目标条件排序反转。低/高抓点在每个场景分别是90/100或100/105mm；质量在场景之间平衡，不是同场景质量因果对照。
3. 实际训练普通Fitted Q、STAP动力学/Q、固定后段价值类比，以及等容量generic、contract、relative、relative+contract终局头；加3个场景bootstrap critic。共享136条训练轨迹（历史64+新72），其余新24条、2场景仅作温度校准。原始模型、分割、标签、权重、每阶段更新量完整保留。相对排序只使用真实后继特征完全相同的8组异结果动作对。合同辅助预测真实终局裕量，不冒充IK/碰撞可行性证明；普通终局监督评分与终局Fitted Q在此有限时域末阶段等价。
4. 发现并修复float32概率饱和导致的选参并列：sigmoid可全部舍入为1；改用logits和对数Q乘积排序。3个数值fixture通过；该修复是标准数值工程，**不是RL创新**。初轮112条全部保留为诊断，仅修正后另跑112条进入主表。
