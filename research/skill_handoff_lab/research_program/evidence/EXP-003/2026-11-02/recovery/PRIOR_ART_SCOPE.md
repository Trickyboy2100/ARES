# Closest-method boundary
This round's ordinary masked critic-LN SAC and grasp/pace primitive interface are baselines, not a new RL algorithm. The native200 action intervention is a physical opportunity study.

- [RAPS](https://arxiv.org/abs/2110.15360) already studies RL over parameterized robot primitives. A new pitch/advance parameter interface alone is not novelty.
- [STAP](https://arxiv.org/abs/2210.12250) and its [official source](https://github.com/agiachris/STAP) coordinate geometric dependencies using learned skills/models at planning time. Previously verified STAP kernel remains retained. No newly trained STAP benchmark is claimed for this new interface.
- A force-threshold feedback law or event-triggered observation is ordinary control engineering. Do not rename it an independent learning method.

The current candidate requirement remains incremental whole-task performance beyond strongest shared controller and sufficiently developed ordinary RL, under identical state/action/physical budgets. Prediction accuracy, a local rescue behind an inferior predecessor, or stochastic planner prefix differences do not satisfy it.
