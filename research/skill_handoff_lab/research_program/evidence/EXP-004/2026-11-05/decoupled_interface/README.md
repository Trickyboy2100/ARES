## 科学结论

**有一个范围明确的正向结果：**在冻结后的32个新自然初态、两个采集/优化随机重复中，active-target接口的成功BC学习器分别17/32、18/32，旧measured接口14/32、12/32；相对共同名义控制的退化从5→2、7→1。它支持执行表示改善能力保持的初步主张，**不是新SAC算法，也没有新增名义失败救回**。名义继续19/32仍最强。

已见开发集的结果反而不支持新接口优势；这一负结果不删。参考分离改善了早期探针的即时命令扰动，但不是充分的学习改进条件。两批新初态分别报告；第二批是见到第一批保持趋势后追加的冻结确认，不包装成预先封存的大样本显著性试验。

新的机制反例进一步修订候选：**零目标偏移的重新规划也可能破坏任务**。759205/grasp1在94个已记录物理步一致后，原队列成功；零偏移重规划生成14点队列，3mm重规划生成15点队列，均在仅剩6步时失败。这里不是“七倍数值放大”。重规划本身足以造成失败，但该实验尚未唯一分离重新生成的关节路径、初速度及时间参数化各自的贡献。

## 4. 实际语义和反证

- 动作0继续当前有效队列，不恢复原始轨迹。
- 动作1刷新实测附着参考；动作2–5在active-target接口中仅改变已有目标的Y/Z平移，保持目标姿态，但仍触发完整MPLib重规划。
- 动作7的hold和初始规划失败以实际保持TCP作为相对参考。目标3mm不是电机3mm，也不是FK误差保证。
- Actor观察64维实际状态和队列摘要，不直接观察完整active target/队列；这是限制，不是额外特权。
- 继承Option使用grasp loss或队列耗尽加规划调用计数代理作终止条件；不能写成已经验证的真实语义接触事件终止。

新增12次同抓持完整物理配对区分前后段作用：759205新策略仅grasp0成功，旧策略三种均成功；759202仅旧策略grasp0成功。94步失败反例来自759205/grasp1。前缀一致指记录的初态及逐步q/qvel/TCP/peg/电机命令一致，使用完整重执行，没有PhysX近似恢复。

另做15次零偏移反证（一个已见案例加四个新机制初态×三分支）。仅上述已见案例出现继续成功、零偏移及3mm重规划失败；四个新案例结果不变。不能把该小组包装为总体发生率或方法成功率。
