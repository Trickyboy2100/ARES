# Version-bound continuation evidence: working hypothesis

The retained executor, 83 observations, three grasp choices, rear13 legal selectors and native100 horizon are unchanged. No new physical ability or safety guarantee is claimed. Initial study fixes the warm predecessor to isolate rear improvement; a separate joint SAC control retains predecessor learning. The frozen final checkpoint is used for the primary developmental comparison, with all intermediate scores retained.

A reference policy is frozen for physical branch collection. A reachable boundary and two different legal choices are selected by scene-index cyclic sampling before outcomes; this is systematic action intervention, not an uncertainty-based acquisition claim. Every branch starts from the original native reset. Equality is checked on the complete recorded prefix, actual observation, queue, cursor, previous action, active reference and budget. This is not a claim of serializing every hidden PhysX solver variable. The common suffix is the same frozen recurrent policy after inherited Option execution. No simulator state restoration occurs.

Each measured pair stores its policy version, real duration, complete trace paths, queue and prefix hashes, and signed terminal outcome difference. Ties stay in transition replay but supply no positive preference. Non-ties define a logistic ranking loss between the executed alternatives. Their actual transitions remain usable for ordinary SMDP learning even after preference labels expire.

Three same-interface arms receive the same initial physical data and equal own-policy and refresh budgets:

- Flat SMDP-SAC with the inherited success-BC term.
- Terminal-outcome supervised scoring plus physical non-tie ranking; no Q-derived Actor gradient.
- The same SAC plus physical preference improvement and an empirical continuation trust region.

The candidate computes KL from the frozen reference's soft distribution on successful **post-intervention** suffix states to the current policy. The intervention state is excluded, so retaining a suffix does not directly forbid the new first choice. The pair gradient is enabled while the minibatch mean suffix KL is below0.05; otherwise only the restoring KL gradient remains alongside SAC. Both ranking and successful-suffix retention are standard ingredients. This particular empirical composition is a falsifiable candidate, not a proven novel algorithm or monotone policy improvement theorem. Soft KL does not ensure identical argmax execution, nor protect unseen states.

At64 own episodes, each arm collects fresh original-reset pairs under its own checkpoint on the same new16-scene training distribution. It retires the old preference/anchor set, keeps compatible transitions, and continues own-policy training. Initial branches compare the warm reference choice; refresh compares the current frozen reference choice, not necessarily the fixed warm action. Thus the refresh estimator is a reference-policy local improvement contrast, rather than an exact implementation of fixed-baseline advantage throughout.

Gamma=1 respects the finite undiscounted native objective. Actual Option duration changes the remaining physical budget; decision entropy is not physically time-invariant. Recorded complete success, rescue and regression determine efficacy. Ranking fit, lower KL, altered logits, or more interventions are not positive method results.

The next matched prototype derives415 observed nodes from the same189 complete physical episodes. Each node keeps exact recorded history identity,83 policy features, and a set of actually executed successful choices. A failed reference choice at an intervention fork is stored separately as a feasibility fallback, not called successful. All decisions of each successful prefix/suffix are retained; both-success pairs can enlarge support but are not treated as positive return advantages.

Two learners share SAC, successBC, current-version physical ranking, data and exploration. The soft learner minimizes the negative log probability mass of the allowable set. The constrained learner instead modifies the proposed Adam parameter displacement: linearize violated allowable-versus-forbidden logit margins, apply sequential halfspace corrections, then check exact nonlinear greedy action membership on every stored node. Backtracking or rejection preserves feasibility when the linearization is insufficient. This is not an exact nearest-point projection onto a convex feasible set. Adam moments are retained; cuts, scaling, rejected steps and compute are recorded. There is no deployment-time action override.

At the common64-episode refresh, both acquire current-policy branches and append successful executed witness support, while old preference comparisons retire. Ordinary compatible transition replay remains available. The graph is cumulative in both arms, separating support retention from soft-versus-projected updates. All algorithms still have13 legal selectors and83 observations. Complete queues identify training evidence but are not additional policy inputs.

Mature precedents include GEM's constrained memory updates, SPIBB's baseline restrictions, ordinary set-valued imitation and projected optimization. The scientific question is whether an execution-specific constraint produces better complete physical policy improvement than same-data soft retention and ordinaryRL. CPU feasibility/resume checks are implementation evidence only; physical training and new-condition performance must decide efficacy. No general safety, originality or independent benefit is asserted at this stage.

## Solver correction identified during actual constrained training

The first projected implementation stalled: at a retained live checkpoint,40 identical-data CPU update attempts were all rejected. This was an optimizer implementation problem worth separating from the scientific constraint. A standard active-set dual QP uses the *actually violating* forbidden action and jointly projects the proposed Adam displacement onto the collected local margin halfspaces. Exact nonlinear membership checking/backtracking remains unchanged. At the same checkpoint/data/RNG,40/40 updates were accepted and all recorded choices remained admissible; exact Actor/Critic resume also passed. These are CPU numerical checks, not physical task gains.

The old64-episode physical prototype is preserved as a failed numerical implementation. The corrected learner starts again from the same shared warm initialization and189-episode dataset for the physical comparison, rather than inheriting an uncharged post-hoc trained model. The soft-support comparator is unchanged. The correction introduces no new reward, observation, action, physical query or predictor. Sequential projection and dual QP are mature numerical methods, not the proposed independent contribution.

## What the constraint cannot establish

An admissible set may include a failed-reference fallback, so satisfying every recorded constraint does not even imply choosing every available recorded rescue. It also does not calibrateQ. A network may preserve all observed choices and fail on a nearby unrecorded physical state. The stored objects are a finite witness set linked to original trajectories, not a learned graph network. Current reference refresh uses new scenes; it does not systematically revisit every earlier witness to discover additional permissible actions. These limitations are explicit and must not be hidden by a feasibility percentage.

The first sequential-projection pilot finishes64 own episodes at10/16, zero rescue and zero regression, while1720/2560 Actor updates are rejected. The complete raw model and trajectory are preserved. This supports retention under severe update suppression, not effective online skill improvement. The corrected dual-QP model is trained afresh under the matched protocol.
