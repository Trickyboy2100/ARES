# 从实际干预证据到在线技能保留：完成的学习循环

基点 `d4a20b0`，分支 `research-sci-program`。本轮保留原生 Peg100、真实抓持、强规划器、83维观测、三抓持与13个后继选择。没有实机操作、物理难度改造或封存测试。入口：[REVIEW.html](REVIEW.html)；复现：[REPRODUCE.md](REPRODUCE.md)。

## 实际做了什么

完成了三个连续机制版本：参考策略绑定的配对排序与KL保留；完整成功见证上的软集合保留/约束Actor更新；固定半参考间隔消融。先修复近似投影的数值停滞，再从相同初始化重新真实训练，未把数值修复当成RL贡献。普通SAC、监督排序、KL、软保留、正确QP各有两种独立网络初始化、128回合各自策略采集、5120次更新及0/64/128检查点。另有真实联合前后段SAC，以及两个64回合有明确用途的诊断版本。总计1536 own-policy回合、61440个联合更新轮（每轮一次Q优化和一次Actor提案；旧投影有1720次Actor提案被拒绝）；共享/刷新/评测成本另计。

## 新的科学认识

1. **平均KL小不等于离散部署动作保留。** 全参考锚定仍能改变必要修正；后续因此比较直接的实际动作集合约束。
2. **数值可行不等于物理改进。** 正确QP两种子5120次更新均无拒绝，最终580/570个记忆节点零动作集合违规；新32场景仍为17/16，普通SAC为17/17。
3. **保留与救回发生冲突。** QP在11个预先选定训练根状态上完整执行10/11，普通SAC/软保留各9/11；新条件中QP没有救回，只减少部分退化。不能把训练见证记忆当泛化。
4. **不能把全部失败都归因于Q低估或续接策略变化。** 768400的成功Option耗尽预算，真实奖励1.1783而普通Q约0.790/0.756，说明该处无需后续策略改变也有估值误差；另一方面768056实测正分支的Q高于参考动作，Actor仍选失败回退。该参考边界不一定被最终策略实际访问，不能独自解释整条失败；两种失效必须分别处理。
5. **剩余预算不等于未完成的后续工作。** 初始4条与新增2条正分支均在Option释放前已达到原生成功；后续多数是维持成功。当前数据不能支持“学会两次以上必要后继干预”的主张。最终仍按第100步判定，后续错误重规划仍可能破坏已达成功，不能因此提前截断任务。

所有模型SHA在打开768600–631之前固定，按final128评价，未挑最佳检查点。这是新的开发确认集，不是封存测试。两种子共用32个场景，不能当64个独立任务。

QP相对SAC的两模型平均差为−1.56个百分点，按场景聚类的探索性95% bootstrap区间为[−12.50,+7.81]个百分点。该区间条件于这两个模型，不代表完整训练种子总体不确定性。KL每种子比SAC多1例，但没有超过warm；不得据此宣称独立方法优势。

**最强固定参照的重要性：** 首次合法边界执行physical5（localZ−）后恢复warm续接，是确认前已固定的策略，不是本批场景上挑出的动作。24/32比warm净多6例，但仍有3例退化；这是一项具体队列/执行策略的物理结果，不是RL贡献或总体显著性结论。本轮所有学习器均未超过它。历史full-option SAC快照也达到21/32，高于本轮新训练SAC；不得把本轮17/32称为现有最强普通RL。后续方法不能继续只把warm当作最强目标。该固定对照用一个本地`used`标志记住是否已经发出首次动作；它没有额外传感/未来结果，但比83维前馈Actor多一个显式控制历史位。因此它是强执行参照，不是网络结构相同的算法消融。

共同数据机制与own-policy主实验分开：每臂共享同一189次初始物理执行，后续使用各自真实采集；64回合后按同一16场景/最多两替代动作规则刷新。合法分支数不同，实际成本逐臂列出。候选并非获得完全相同的后续轨迹。QP额外计算也如实计入，不能声称CPU预算完全相同。

## 实际动作机会与边界

初始64自然设计场景：warm35，有限采样并集38；189次完整执行得到125条配对，4正/22负/99平局，正例来自3个场景。新增策略分歧采集：32自然场景、65次完整执行、33条配对，2正/4负/27平局，两个正例都来自768084。warm22，有限并集23。后者未供本轮冻结模型训练，两个采集设计也不是同场景随机对照，不能宣称采样效率提升。

所有配对从原生初态重执行，匹配记录的物理前缀、队列、游标、参考与预算；不使用近似PhysX状态恢复，也不声称比对了每个隐藏求解器变量。83维是实际可用观测，不等于包含完整规划队列的Markov状态。正负分支和失败模型全部保留。

## 论文主张与后续方向

可进入Method/Experiments：完整可执行Option语义、参考版本绑定的真实续接数据、累计成功见证的实际更新算法、普通RL/监督/软硬保持的同权限对照、优化停滞修复与物理反例、独立初始化和完整成本。

当前**不支持**独立RL性能优势、安全策略改进保证、已证明的联合前后段协同、第二任务方法迁移或投稿就绪。状态仍为 `UNVERIFIED_INDEPENDENT_ALGORITHM_GAIN`，但实现、图表、方法段落和全部证据已经保留。

下一项有依据的研究不应继续调大KL/投影强度：应先区分真实可验证成功集合和仅为初始化可行性留下的失败回退，并检验成熟价值校准/策略改进能否解决Actor拒绝已知更好Option的问题；同预算成熟基础必须共享。与此同时，继续寻找实际后继工作尚未完成时的合法决策窗口，不能用成功后的剩余步数代替多阶段学习需求。
