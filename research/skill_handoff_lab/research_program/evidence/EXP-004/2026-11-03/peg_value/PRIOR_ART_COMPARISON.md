# Code-level comparison and claim boundary

- STAP: pinned 0fe0dcbd5ede5ce4ee3d952642f70b5550a0813c; existing ARES original-kernel fixtures retained. Skill feasibility Q, learned transition and policy-initialized CEM are existing machinery. This round uses an explicitly labeled discrete candidate-enumeration Q-product/dynamics comparator, not the official CEM benchmark or a retrained full STAP implementation. [Code](https://github.com/agiachris/STAP).
- SeqDex: inspected bi_optimization.py and transition_value_trainer.py at the pinned revision in prior_code/SeqDex_PIN.json. Success/failure terminal data train a transition feasibility classifier with balanced batches, then feed policy sequencing. Our auxiliary directly constrains action-value differences at identical measured handoffs; merely using SkillResult or successor labels is not new. Restricted source is not republished. [Code](https://github.com/sequential-dexterity/SeqDex).
- Foresight: offline downstream rollout statistics supervise terminal-state future success, used in backward residual training. Our foresight entry is a state-based mean-suffix target analogue with a common terminal critic, not its visual VLA implementation. The official project URL could not be retrieved in this session; this comparison uses the paper, not inspected Foresight source. No official runnable checkpoint reproduction is claimed. [Paper](https://arxiv.org/abs/2607.16506).
- DAWN: inspected pi_dec_diffusion_maniskill2_dawn.py and network definitions (revision/hash index retained). Base data warmup, critic LayerNorm and residual SAC are baseline techniques. Existing masked LN-SAC is inherited. Extra supervision, whether paired or absolute, uses the same original data; additional backward compute is reported and is not a new physical query. [Code](https://github.com/Guozheng-Ma/DAWN).
- RAPS: inspected parameterized-primitive experiment configurations. Learning primitive/argument policies is prior art; our two-boundary interface is not itself a contribution. [Code](https://github.com/mihdalal/raps).
- Fabrica: inspected assemble task action preprocessing and reward; path-aligned control and planned assembly plus learned contact execution already exist. The Peg adapter is not an assembly algorithm claim. [Code](https://github.com/yunshengtian/Fabrica).

Candidate tested, not asserted novel: L = L_SAC + mean[(Q(s,a_i)-Q(s,a_j) - (Y_i-Y_j))^2] for genuinely identical physical-prefix pairs. The hypothesis is that cancelling a shared state offset better preserves executable parameter ranking. Same observations, labels, action range, actor/critic architecture and update counts; absolute-target and shuffled-pair controls test whether ordinary label anchoring explains any benefit. Fitted-Q and mixed-label sampling variants were also actually trained. No extra effect predictor or reward shaping is added. All prior-art comparison remains conceptual/code-level except the explicitly identified functional comparators and inherited kernel tests.

Result: early logged-selection gains largely match generic supervision and do not survive as an independent full-task physical improvement. This candidate is a retained negative implementation, not a publishable contribution. The shuffled auxiliary run consumes a local random permutation before minibatch training, so identical seed does not guarantee an identical minibatch stream; the primary ordinary/paired/absolute comparisons do not have that shuffle perturbation.
