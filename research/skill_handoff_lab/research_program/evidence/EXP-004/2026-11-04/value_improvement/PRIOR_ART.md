# Closest methods and claim boundary

- [VIAC, NeurIPS2025](https://arxiv.org/abs/2406.01423): separates the acting policy from value improvement. We inspect the official SAC implementation at the pinned commit in PRIOR_CODE.json and adapt its expectile critic loss with tau0.75. Exact finite soft value improvement is another shared baseline. Neither is original here.
- [USAC, ECAI2025](https://arxiv.org/abs/2406.03890): independently controls actor and critic utility aggregation. The reviewed code uses mean plus g(kappa) times ensemble population standard deviation. Our categorical functional control uses kappa_actor0 and kappa_critic−0.831559, approximately mean-actor/min-critic; this is an explicit framework configuration, not a full published-benchmark reproduction.
- [BEE/BAC, ICML2024](https://arxiv.org/abs/2306.02865): blends exploitation of replay experience with current-policy soft evaluation. Our finite counterpart uses lambda0.5, expectile0.7 and exact categorical expectation of the entropy term. An extra V update is disclosed. Code is independently implemented from the reviewed algorithm, not redistributed.
- [Q-graph](https://arxiv.org/abs/2007.07582): already uses empirical transition structure and value bounds. The lower-bound control is a task-specific empirical analogue. No official Q-graph source was located in this search; we do not claim source-level reproduction.
- [STAP](https://github.com/agiachris/STAP): inherited verified core and log-Q repair remain intact. This study uses its disclosed finite functional skill-Q/dynamics/suffix composition, not the complete original planner, uncertainty system or leaderboard setup.
- [SeqDex](https://github.com/sequential-dexterity/SeqDex): reviewed stored transition_value_trainer uses success prediction and transition-value guidance. [Foresight Residual RL](https://arxiv.org/abs/2607.16506) uses terminal-state downstream value. Both precede a general claim of conditioning predecessors on successor outcomes. Same-data conditional outcome scoring is included, but is not labeled a complete reproduction of either system.

All compared finite learners share54-dimensional privileged simulated state, original success/horizon, physical controller, legal Option set, data and nominal update schedule. LayerNorm, normalization, exact finite actions, mean-Q, IQL/FQI/CQL and offline-online replay mixing are standard assets. Fixed alpha0.02, small shared networks and finite discrete actions differ from original continuous-control implementations; superiority over their full systems is not claimed.

The candidate replaces learned terminal action values in a soft predecessor backup with actually executed returns only at exactly matching measured handoffs. Complete-coverage revision enables this replacement only when every currently legal successor was physically observed. This changes the learned deployed Q, not an auxiliary prediction head or data acquisition score. It overlaps empirical dynamic programming/Q-graph ideas, so the present code is an experimental mechanism, NOT established independent novelty. Its failure to exceed ordinary RL is retained. The negative paired-loss and effect-direction experiments were not renamed or expanded.
