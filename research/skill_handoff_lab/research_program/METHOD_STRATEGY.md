# 方法演进阶梯：在哪里可能获得真实独立RL增益

> 本文是研究策略与待验证假说；不宣称已实现新的成功方法。
> 每一阶先排除更简单的解释，再添加复杂机制。方法和任务可变，科学问题稳定。

## A. 上一阶段为什么没有“增益”

StackCube强控制或普通Residual PPO接近饱和；Pyramid已测9候选的最佳
固定参数59/64、oracle成功并集62/64，开发组后段基本都可完成。
最新Charger 12个设计状态×9候选只有18个正成功标签，小网络FittedQ
不稳定且没有任何在线接触重决策。动作效果本身有真实影响，但当前
“仅两次预先参数选择→二元终态回传”没有为学习提供足够有效的信息。

## B. 不一次堆三个新网络

**L0 先把名义控制做强**：修复物理跟踪/预算/姿态问题并保存为冻结baseline。
做真实规划search、几何反馈和合理的接触控制。其改进属于基线，不归因RL。

**L1 证明有效可执行动作**：在保持物理/成功/horizon与强控制相同的条件
下，开放少量局部参数如侧向位置/姿态/推进幅值，必要时受约束撤回。
在接触后关键事件继续选择参数，而非只能在抓取前选一个离散角度。
测量 issued/clipped/applied、工具/工件真实运动与接触。验证合法控制
能正向救回部分完整任务失败，并定量揭示对原本成功任务的退化风险。

**L2 成熟的学习基线**：相同接口与状态的普通ResidualPPO和ResidualSAC。
可基于DAWN已有的名义数据/critic LayerNorm提升训练，不把其贡献重命名。
完整控制步与有效策略决策数分开统计；名义数据预采集计费。
测试state-based上限与同信息的generic history，避免只因多输入提升。

**L3 核心候选（优先，只选一个）**：真实执行作用的状态条件化表征。
针对当前任务条件 \(c_t\)、观测 \(o_t\)、实际执行动作 \(a_t\) 学习
\(\hat e_{t+1}=f_\phi(o_t,a_t,c_t)\)；执行后得到
\(\epsilon_{t+1}=e_{t+1}-\hat e_{t+1}\)。利用该效果残差更新实际接触状态
或策略价值。必须证明它**进入未来动作选择/梯度**，与仅增加短时历史、
更大同容量网络、以及强规则在线重规划比较。不能把这套通用形式本身
当原创，因为SCOUT和诸多residual/model-based方法已有相关设计。

**L4 只有独立L3收益后再选第二项**：如剩余预算条件的值函数、低维
option recovery或可信的不确定性修正。若先加入多项，做全因子消融，
并承认可能是原有方法重新组合；不要默认“更多模块=科研贡献”。

## C. 为什么这个方法有希望，而上一轮失败

- **控制层面**：接触后修正是新的真实决策机会，不是事前猜一个最优高度。
- **学习信号**：每次有效接触动作的物体/工具相对运动能产生连续目标，
  比稀疏终态二元标签更有信息，但这些目标是否真的有助于策略须单独验证。
- **时间抽象**：名义抓取/搬运仍由强执行器完成，仅接触/关键事件阶段
  的短局部控制学习可提升样本使用；最终必须全任务冷启动检验。
- **任务适应**：在对象/工具/目标/摩擦变化中学习参数规律，而非记场景ID。

以上均是**机制为什么可能有效的假设**，不是统计增益证明。

## D. 数学对象与算法选型

合法动作：
\(u_t=\Pi_{\mathcal C_t}[u_t^{nom}+\Delta_\theta(o_t,h_t,c_t)]\)。
若实际只有单次参数选择，属于contextual bandit；在多次物理事件中
闭环更新，则为持续MDP/事件级SMDP。不要把任何多次动作都称技能Option原创。

价值可用标准 off-policy Bellman backup：
\(Q(o,h,a,c,b)=\mathbb E[r+\gamma^{\tau}V(o',h',c,b-\tau)]\)，
其中 \(b\) 是剩余预算，\(\tau\)是真实执行持续时间。
使用真实合法后缀与正确终止，不能用伪造中间reset/成功。
这仍是已知RL算法基础，创新应具体化在经过测试的输入/作用估计与决策机制。

**初期算法**：优先复用成熟 Residual SAC 与上游普通ResidualPPO作为学习能力
对照；极小离散技能搜索可用监督ranker/contextual bandit，不强行套SAC。
实测离策略价值无法稳定时，分析Q标度/名义预热/探索/偏差，而非立即加新头。

## E. 主要学习任务与对比

| 实验条件 | 直接回答 |
|---|---|
| 强名义+真实几何重规划 | 传统方法已经做到哪里 |
| 名义+同权限固定/搜索/CEM | 只调参数是否已经足够 |
| 同动作/同观察Residual PPO/SAC | 普通在线RL能学到多少 |
| +短时历史（同大小） | 仅多记忆是否足够 |
| +真实作用残差表示（同数据预算） | 物理效果建模是否独立有效 |
| +预算/恢复（可选） | 新增机制是否还有第二层贡献 |
| 去掉模型反馈/重决策/next-contract | 哪部分导致真正收益 |

**主结果：**原生完整任务终态成功；另报配对救回/退化、完成物理步骤、
接触质量、规划/推理成本、训练episode及有效RL决策数。
不能仅报告参数正效应视频、Critic loss或成功条件子集。

## F. 任务选择规则

当前优先 PlugCharger-v1：原生200步，已实测局部参数使终态偏差
22.05→3.66mm且有0→1，但8个已看开发场景中强固定2、监督3、FittedQ1；
基线和随机性仍需核查；**不是已验收可产生稳定方法增益的任务**。
PullCubeTool-v1强几何前瞻7/8，可作为第二物理机制/泛化；若它完全
饱和，不强行再训练。
有必要时采用新的工业合理操作或官方其他ManiSkill任务，以是否有
可测量、可学习且强控制未解决的接触适应缺口为选择依据。任何自定义
改动需独立标注，不冒称未修改官方benchmark。

## G. 核心停止与转向原则

不是“没有成功率增益就结束研究”，而是：
- **任务物理控制无效** → 重新设计真实参数和任务；
- **强规则足够** → 更换能体现学习优势的合法任务条件；
- **动作有效但学习失败** → 调成熟RL基座、数据覆盖和有效观测；
- **普通RL成功新机制无效** → 不称新方法，检查信息是否已包含；
- **新机制稳定正增益** → 进入独立测试/种子和论文证据阶段。
