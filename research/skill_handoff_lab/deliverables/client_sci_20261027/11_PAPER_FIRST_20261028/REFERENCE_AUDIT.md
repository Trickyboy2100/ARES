- RAPS: Murtaza Dalal, Deepak Pathak, Ruslan Salakhutdinov. *Accelerating Robotic Reinforcement Learning via Parameterized Action Primitives*. NeurIPS34,2021. [Official proceedings](https://proceedings.neurips.cc/paper_files/paper/2021/hash/b6846b0186a035fcc76b1b1d26fd42fa-Abstract.html). Corrected erroneous old short title in10_METHOD_EVOLUTION/PAPER_METHOD_EVOLUTION.tex. No publisher DOI supplied on this page; none invented.
- STAP: Christopher Agia, Toki Migimatsu, Jiajun Wu, Jeannette Bohg. *STAP: Sequencing Task-Agnostic Policies*. ICRA2023,7951-7958. DOI10.1109/ICRA48891.2023.10160220. [Author repository and BibTeX](https://github.com/agiachris/STAP). Already uses geometric skill dependencies and skill-Q planning; downstream feasibility is not our invention.
- ViSkill (surgical robot, not the unrelated2026 VLM paper with the same short name): Tao Huang, Kai Chen, Wang Wei, Jianan Li, Yonghao Long, Qi Dou. *Value-Informed Skill Chaining for Policy Learning of Long-Horizon Tasks with Surgical Robot*. IROS2023, arXiv2307.16503. [Primary paper](https://arxiv.org/abs/2307.16503), [author code](https://github.com/med-air/ViSkill). No unverified IEEE DOI inserted.
- Foresight: Yuhan Liu, Xinyu Zhang, Litao Liu, Abdeslam Boularias. *Foresight Residual RL for Long-Horizon Robot Manipulation with Vision-Language-Action Models*. arXiv2607.16506,2026; author page lists IROS2026 acceptance. DOI10.48550/arXiv.2607.16506 is the arXiv DOI, not an IEEE proceeding DOI. [Primary page](https://arxiv.org/abs/2607.16506). Already explicitly shapes terminal handoff quality from downstream-success predictions.
- DAWN: Guozheng Ma, Lu Li, Haoyu Wang, Zixuan Liu, Pierre-Luc Bacon, Dacheng Tao. *What Makes Value Learning Efficient in Residual Reinforcement Learning?*. ICML2026, PMLR306:84569-84601. [Official proceedings](https://proceedings.mlr.press/v306/ma26s.html). Base-data anchoring and critic normalization are prior methods. We use PPO, not SAC/LayerNorm DAWN, and do not claim a DAWN reproduction.

Current manuscript cites these verified sources only. Historical10_METHOD_EVOLUTION assets are retained as dated evidence, not regenerated into new results. No abstract benchmark numbers from these papers are reused as a local comparison.
