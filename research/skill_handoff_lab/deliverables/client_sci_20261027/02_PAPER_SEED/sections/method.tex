\section{Implemented Basis and Candidate Method}
\subsection{Nominal control and ordinary residual PPO}
The damped nominal controller tracks a stage target while respecting a fixed legitimate pushing side. Reference lead over the actual tool is bounded to 6 mm to prevent integral windup. Ordinary residual PPO adds at most 0.6 mm per control step in planar reference corrections. All methods share the same DLS joint controller and physical constraints. This strong nominal policy is retained and improved alongside any task-frame transformation; it is not weakened to manufacture an RL advantage.

The historical learning comparison uses 16 environments, a $[64,64]$ MLP, rollout length 256, six minibatch epochs and $\gamma=1$. Each main model receives 65,536 online interactions. Final checkpoints are fixed by interaction budget, not selected on the frozen tests. PPO optimizes the usual clipped surrogate with GAE. A separate diagnostic mixes GAE with a current-rollout, value-bootstrapped $\lambda=1$ target; it does not reuse stale episodes across policy updates and is not presented as a new credit-assignment method.

For clarity, the policy update is ordinary PPO \cite{schulman2017ppo}, with likelihood ratio $r_t(\theta)=\pi_\theta(a_t|o_t)/\pi_{\rm old}(a_t|o_t)$:
\begin{equation}
 L_{\rm actor}=\mathbb{E}_t\!\left[\min\{r_t\hat A_t,
 \operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\}\right].
\end{equation}
Context or history changes this distribution's inputs, not the estimator into a new credit-assignment algorithm. The value loss and optimizer use the same data budget as their matched baselines.

\subsection{Task-frame baseline B2}
The new development comparison converts task errors, velocities, object orientation and permissible reference directions to the local entrance frame. B1 retrains the BODY-XY residual on the same new physical cases; B0 is the repaired task-local controller. B1/B2 share source physical state, input size, capacity, physical action range, reward and interaction budget, but exact information equivalence is not guaranteed. In particular, B2 canonicalizes the explicit entrance-direction cosine/sine to 1/0 while joint state and physical workspace remain in BODY coordinates. This is neither a strictly invertible whole-state transform nor a demonstrated rigidly equivariant policy. Any B1/B2 difference is a bundled engineering/representation comparison, not an isolated proof of frame causality. B2 and B3 retain the same base representation, supporting the targeted history ablation.

\subsection{Outcome-aware candidate B3}
The implemented B3 pilot adds eight one-step history channels to the historical 56-state basis: task-forward/lateral object finite-difference velocity (two), previous applied reference increment divided by control duration (two), their differences (two), object angular velocity about the vertical axis (one), and the previous normalized phase-0 contact-target command (one). The last quantity is a requested parameter, not an observed workpiece displacement. Each channel is bounded in observation preprocessing. These signals directly enter the actor; no future success label, learned predictor or disconnected auxiliary loss is used.

All learned pilot methods have three continuous outputs: planar residual correction bounded to 0.6 mm/control step and a phase-0 lateral contact-target offset bounded to 4 mm. Only the tool reference changes, not the physical object or task goal. B1/B2 set the extra eight history channels to zero but retain the same 64-dimensional input and network. They still observe current pose, velocity and contact proxy, so this ablation is called \emph{no effect-history}, not absence of all physical outcome information. The downstream-goal ablation masks phase-0 future-target and some entrance-geometry channels while retaining mass/friction context; the legal action mapping still uses the known task direction. It is a \emph{partial} next-contract intervention, not a policy with no downstream information.

Writing $R_g$ for the planar task rotation, the measurable response part is formed as $R_g^\top(x_{o,t}-x_{o,t-1})/\Delta t$ and $R_g^\top\Delta x_{{\rm ref},t-1}/\Delta t$, together with their difference. The requested contact parameter is $4\,\mathrm{mm}\,\operatorname{clip}(a_{t,3},-1,1)$ in phase 0. It changes the controller's lateral contact target while the physical workpiece goal remains unchanged; rear-face alignment and reference antiwindup can suppress its instantaneous physical effect. A nonzero parameter command alone is not executed displacement. A cold-start paired probe records actual applied references and object trajectories to test whether it affects subsequent results.

This is ordinary full-chain-reward PPO with a real parameter-action interface. It does not implement a learned successor Q-function or learned stage termination, and history concatenation alone is not a new algorithm. Its scientific status is a prototype whose independent benefit must be tested. The actual run-source snapshots and protocol define the implementation; a single identified pre-fix observation-index error is preserved as diagnostic data and excluded from the corrected formal pilot.

\subsection{Falsifiable ablations}
The mechanism comparison removes outcome history, removes the next contract, provides capacity-matched ineffective conditioning, or trains a predictor without connecting it to policy decisions. These controls are required to separate information, representation, extra data and actual mechanism effects. Not-yet-run cells remain explicitly untested. A finite search or supervised scorer is included only when the implemented parameter decision has a well-defined candidate interface; a one-shot choice is labelled a contextual bandit rather than long-horizon RL.
