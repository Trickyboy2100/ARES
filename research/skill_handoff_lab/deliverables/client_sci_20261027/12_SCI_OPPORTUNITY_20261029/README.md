# 科学机会与有界实验结论 · 2026-10-29

基线 `ee44ec833d3dd9424b2941f204a7057abb7148e0`，原工作区干净并保留。仅本地 GPU0、网络隔离的原生 PhysX；ARES-R 只读，无现场资料。**本轮没有获得独立方法增益。建议停止在当前 Pyramid 参数接口上增加训练量，把下一轮预算用于更有决策空间的“工具抓持→接触→拉动”原生任务。** 这一建议是待验证的研究选择，不是新任务已成功的声明。

本轮实际训练 5 个双边界模型、3,000 次优化更新，新增 104,000 个原生控制步（416 回合，均为 native250）。没有扩大五种子、打开封存测试、生成视频或重编论文。全部更新属于离线监督/有限时域 Fitted Value；没有把旧 PPO 训练计为本轮训练。

## 1. 真正还有多少可学习收益

旧设计集 64 初态 × 9 组合 = 576 条真实物理执行：

| 参数选择 | 原生成功 /64 | 含义 |
|---|---:|---|
| 名义 A1,C1 | 52 | 固定控制 |
| 最佳固定 A0,C0 | 59 | 用设计集选出的强固定基线 |
| 只选 A，C 固定名义 | 60 | 事后上限 |
| A 固定名义，只选 C | 57 | 事后上限 |
| 联合选 A,C | 62 | 已测有限动作集的事后上限 |

相对最佳固定，联合自适应最多 **3/64=4.69pp**；固定最佳前段 A0 后，C 自适应最多 **1/64=1.56pp**。这是已测网格的机会估计，不是所有连续合法参数的物理上限，也不是可部署策略表现。两个九组合全失败初态 420031、420047 均为 `A_NOT_GRASPED`：当前 A 参数只影响抓起之后的放置方向，根本没有权限修复此前的抓取失败。

### 故障位置和因果归因分开

- 前段未验证：33/576（11 个独立前段上下文，三种 C 重复计数）；18 次 A 未抓住，15 次 A 边界未通过。
- A 已验证，C 未完成：36/576；28 次未抓住、4 次初抬丢失、4 次 C 边界失败。
- 两个局部边界都通过但原生终局失败：2/576。420010/A0/C1 与 420023/A2/C0 的 AB 间距分别越过原生限制 1.11、1.92 mm。局部“已释放且稳定”不等于完整任务成功。
- 其余 505/576 为原生成功。

**前段成功但后续不适配**有配对证据：固定 C 名义，在 A 均合法完成的分支中，9 个初态因 A 参数改变而改变终局结果。**后段自身动作可修正**有配对证据：181 个后段起点中，18 个起点（13 个初态）改变 C 参数可改变结果，三分支起点观测、记录的机器人关节位置/速度和所有物体姿态/速度，362 次分支比较的最大差均为 0。两类初态重合 6 个，不能硬凑互斥因果百分比。158/181 个起点三种 C 全成功，5 个起点全失败；全失败不证明所有合法后段控制都无解。错误字符串只定位发生阶段，不足以排除上游几何影响。

## 2. 风险模型为什么失效，反馈到底新增什么

原风险是“名义成功而改参数失败”，不是所有失败标签：735 个有效 token 仅 13 个正例，来自 12 个初态。245 个名义动作 token 天然为零；去掉后仍仅 13/490=2.65%。前段 5 个、后段 8 个正例。拟合组只有 9 个正例，校准组 4 个；重复动作和共享初态使 token 数远大于独立证据数。400 轮高容量拟合没有校准机制，训练 Brier 0.000029 不代表可靠风险。

旧校准 Brier 0.023302，甚至差于只用训练集正例率的常数预测 **0.020738**。预测平均风险 0.00651，实际 0.02116；最高风险单例反而为负例。不能解释为风险真的接近零。下一步若继续使用风险，应预测可控的条件退化，并采用按初态分组的校准，而不是扩大同一稀疏标签网络。

57 维输入已经含实际物体相对位置/姿态、TCP 相对位置、关节位置/速度、阶段及剩余时限。AB 距离、余量、方向可由已有几何重算；阈值三维为常数。“后验位移”是当前位置减初始位置，在当前状态和初态均已知时没有额外信息。它可作为有用表示，但不能单独宣称新反馈机制。

这仍不是严格完整 Markov 状态：没有物体线/角速度、接触模式；稳定阈值只限制速度，没有令速度为零。控制器也有阶段/初始参考记忆。旧 `no_posterior` 还删除了当前几何并向冻结风险网络送入分布外输入，因此不是干净的历史信息消融。本轮仅去掉 39:48 位移通道，保留实时几何，重新训练后仍为 30/32；小样本无差异不证明历史永远无用。

## 3. 两轮同数据价值实验与执行探针

前四模型仅用旧 48 个训练初态，后 16 个用于报告校准、不选超参。两阶段各 57→64→64→18 的网络，固定种子 20261029、各 300 轮 Adam、相同初始化和参数量；动作权限都是 A 三方向、C 三抓取角。

- **supervised**：终局标签，A 目标为同一 A 下三种 C 的平均回报。
- **fitted_value**：C 学终局值；A 用真实前段转移回传 `I(A verified) × max_c Q_C(s',c)`。是既有技能价值串联思想的有限时域实现，非新的方法贡献。
- **contract**：同样回传，增加实际边界有效性、定位余量、AB 余量、支撑投影重叠、剩余时限的辅助回归，权重 0.2；未到边界的连续标签使用 mask，不造零值。
- **contract_no_history**：同上，仅移除位移历史通道。
- **contract_contact**：根据失败诊断追加；C 辅助量改为实际闭爪的抓取结果、TCP-物体偏差、跟踪误差、物体移动、指间距，覆盖所有 543 个已访问 C 抓取。目标只在训练使用；部署策略仅读取当前 57 维。复用同一开发集，属于适应性探索，不冒称再次未见测试。

| 方法 | 成功 /32 | 对名义救回 | 对名义退化 |
|---|---:|---:|---:|
| 名义 | 30 | 0 | 0 |
| 几何强规则 | 30 | 1 | 1 |
| 设计集最佳固定 | 30 | 1 | 1 |
| 旧普通 PPO，seed31 | 29 | 1 | 2 |
| supervised | 30 | 0 | 0 |
| fitted_value | 30 | 0 | 0 |
| contract | 30 | 0 | 0 |
| contract_no_history | 30 | 0 | 0 |
| contract_contact，分进程探索记录 | 29 | 见下文 | 见下文 |

初态 530000–530031，各方法冷重置 SHA 一致。**名义的两次失败都是前段失败，30 次合法移交后全部成功**；这个开发集没有名义后段救援事件，不能用它宣称跨阶段学习机制被充分否定。模型确实选择不同参数，但大部分差异落在全部可成功的区域。分进程闭爪辅助在 530028 出现一次 C 边界失败，但与原 fitted_value/contract 选择的 A1,C2 **完全相同**。追查发现规划回退随机性和跨进程缓存不共享构成混杂，因此不能把 30→29 归因于学习方法。补做同进程、严格状态匹配共享规划缓存的 32 初态对照后，**fitted_value 与 contract_contact 都为 29/32，成功/失败案例完全相同，0 救回、0 退化**。原始分进程结果完整保留，未覆盖。这个复核耗费额外 16,000 步，没有重新训练；第一轮表内八方法原本就在同一进程运行。

C 校准 Brier：监督/普通回传 0.07217，边界辅助 0.06964，闭爪辅助 0.07190。略好的概率误差没有转化为成功率优势。A 的回传最优后续值与观测均匀后续回报不是同一估计对象，已在 TRAINING.json 标注，不横比其 Brier 排名。

公平性边界：四个初始离线模型数据/架构/优化次数严格匹配；接触辅助额外读取同批真实轨迹。旧 PPO 另有 48,000 在线步及不同训练目标，属于有额外预算的实用参照，非相同训练预算的算法优劣证明。固定基线使用整个旧 64 设计集。没有复现官方 STAP/ViSkill 全套训练，不能声称超过这些方法；[STAP](https://github.com/agiachris/STAP)、[ViSkill](https://arxiv.org/abs/2307.16503) 已建立后续价值串联思想。

### 物理诊断比再加训练更有信息

读取全部 36 份原始轨迹：6,518 次规划均返回路径，故“规划成功”标签在本样本完全饱和。28 次 C 未抓住的闭爪跟踪误差中位数 35.17 mm，515 次检测到抓取为 6.63 mm；物体自移交后移动中位数分别 22.34、3.75 mm。这是执行后关联，不是将未来误差输入策略，也不是碰撞因果证明。规划器未建入桌面/立方体世界障碍，故规划可达本就不是接触可执行证书。

已知故障初态两个批次，单变量将 C_REACH/C_DESCEND 的路径索引步长 3→1；目标、控制增益、六次跟踪补拍、250 步原生限时均不变。31 个已到后段的起点观测逐项一致：**原版 28/32，完整采样 27/32，0 救回、1 退化**。420052 用尽原生时限。慢一点并未修复三次原有 C 抓取失败，否定了“仅降低速度即可解决”的简单解释；不能据此判定跟踪误差无关。

## 4. 论文路线决定

历史 R3 三种子未超过同接口 PPO/强反馈；StackCube 已饱和，旧 Peg 强控制仅 1/8；上一轮 Pyramid 风险 PPO 对普通 PPO 三种子差为 0,+1,-1。本轮也没有支持扩大这些实验的证据。

论文需要解决的科学问题应当是：**在相同可执行参数权限下，如何用任务条件和真实执行残差估计“当前技能完成后，下一技能仍可执行”的动作价值，并在有真实改善空间的状态修正参数？** 有完整状态时，把派生反馈重新命名并不产生创新。普通价值回传和多任务辅助头也不构成独立贡献；本轮未证明原创方法。

下一轮收敛到原生 `PullCubeTool-v1` 的工具抓持→钩入→拉动机会实验：工具抓持位置/姿态改变 TCP 到工具接触点的实际变换，后段钩入偏置有清晰的任务条件化意义。仓库已有官方 Panda 规划解；原生标准为 cube 到机器人基座 XY 距离 <0.6 m、100 步。**本轮仅核查源码，没有声称该强基线已验收或新任务已有增益。**

优先用少量配对物理执行同时比较官方/改进名义控制、固定参数搜索和两个边界的合法参数；记录实际工具到 TCP 变换、钩入余量、物体进展与限时。把“任务可行余量”与“执行残差预测”分开做消融，比较相同信息的规则、监督评分、普通 RL 和后续价值回传。重点寻找保持前段成功而真实改变后段可执行性的参数，避免通过故意削弱名义控制制造提升。若原生 100 步下控制器仍不足，先修复并公开强基线预算；不擅自延长任务或把控制器修复算作 RL 创新。这是下一轮可并行推进的实验顺序，不是阻断探索的机械 Gate。
