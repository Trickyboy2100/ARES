# 技能参数机会验证：PullCubeTool → PlugCharger（2026-10-29）

基于 `8f201b5`。论文主线不变：**任务条件化的可执行技能参数强化学习及跨阶段适应**。本轮结论是有真实物理参数效应，但尚无可靠 RL 方法增量；不扩大网络训练。

直接打开 [证据浏览页](index.html)，或单独播放 [Pull 同初态抓持对照](visuals/pull_grasp.mp4)、[Charger 同前段状态后续参数对照](visuals/charger_handoff.mp4)。视频为真实仿真执行记录的姿态回放，非实机、非理想化动画、非新的实验。原始数据在 `recorded_physics.tar.gz`，全部 388 次完成回放均保留。

## 研究决策

1. **PullCubeTool 暂不作为新 RL 方法的主攻任务。** 官方 100 步规划器在初始 4 例中 0/4，主要在 350 mm 抬升阶段耗尽预算。修正抓持方向、实测持物变换和执行节奏后，同组达到 3/4。干净参数设计的 8 例中，105 mm 抓持固定方案达到 8/8，显示大部分收益可由固定几何改参获得。但它在 8 个新初态仅 5/8；物体朝向条件化后 6/8，再加有界抓持/钩入前瞻规划为 7/8。**不能称强规则已解决整个任务，也没有证据必须依赖 RL。**
2. **PlugCharger 值得保留为跨阶段物理诊断任务，但暂不能认定为成熟论文基准。** 官方与仅更新实测抓持变换的控制器均为 0/4；加入实际物体位姿误差的积分反馈后为 2/4。12 个训练设计初态、每例 9 个合法组合，固定最优组合 5/12，实际执行并集 11/12，18/108 条为成功。这个差距是有限观测中的机会线索，**不是可部署策略成绩，也不是确定性 oracle 上限**：若干前段重复执行存在差异。
3. **本轮检验的“末态几何裕量辅助价值”假设未获支持。** 冻结执行器、动作权限和物理数据后，小规模有限时域 Fitted Q 不如固定参数；添加几何裕量辅助目标也没有救回该退化。监督评分仅净增 1/8，样本不足以声称泛化提升。应优先研究“参数是否允许后段在剩余预算内完成并保持有效抓持”的动作条件化价值，而不是继续放大当前 max-Q 回传或稀疏成功网络。

## 独立初态比较

训练：721000–721003 + 722000–722007；比较：723000–723007，未用于选参或调训练超参数。原生 PlugCharger **200 步**及成功条件不变。五种方法共用同一低层执行器；抓持倾角 {-15°, 15°, 45°}，抬起后接近距离 {25, 50, 75 mm}。

| 方法 | 原生成功 | 相对固定方案救回 / 退化 | 每例墙钟中位数 | 规划耗时中位数 |
|---|---:|---:|---:|---:|
| 训练集网格搜索得到的固定参数 | 2/8 | 0 / 0 | 5.209 s | 0.0529 s |
| 固定最优抓持 + 当前状态几何重规划 | 2/8 | 1 / 1 | 5.089 s | 0.0679 s |
| 监督评分 | 3/8 | 2 / 1 | 5.075 s | 0.0512 s |
| 普通技能级 Fitted Q | 1/8 | 0 / 1 | 4.870 s | 0.0511 s |
| 几何裕量辅助 Fitted Q | 1/8 | 0 / 1 | 5.094 s | 0.0515 s |

墙钟包括物理执行、记录与文件写入，不是单纯 GPU kernel 时间；200 步对应 10 秒仿真时间。规划成本另记，不能把总墙钟当成推理时延。固定网格、监督和两种 RL 使用同一批 108 条网格执行数据；几何方法只增加最多 3 次当前状态规划查询，不增加物理试错。**这是等物理数据预算比较，不是严格等 CPU 计算量在线搜索比较。**

### 失败归因与退化

以下为可观察的运行分类，不能仅凭终态推断唯一物理原因：

- 固定参数 6 次失败：1 次前段未通过抓持/抬起检查，4 次后段末态原生抓持信号为假，1 次仍有抓持信号但未达原生目标。
- 普通 Fitted Q 的 7 次失败：前段未验证 2，后段末态无抓持信号 2，仍有抓持信号但目标未达 3。
- 裕量辅助 Fitted Q 的 7 次失败：前段未验证 1，转场/预算未完成 1，后段末态无抓持信号 3，持物但目标未达 2。
- `is_grasping=False` 是原生接触判据，不自动等于物体已掉落。完整轨迹提供物体位姿/速度和接触力以供复核。
- 723002：固定 15°/25 mm 成功，监督和两种 FQ 改为 45° 后均失败。723001：监督改变后段距离救回，但普通 FQ 改抓持为 45°，连前段抓持检查都未通过。723005：几何与监督选 15°/75 mm 救回，两种 FQ 选择 45° 后失败。说明当前最大后续 Q 回传可能诱导不可靠的前段选择；这是与观测一致的解释，尚未通过单因素重复实验确立因果。

## 两组有物理意义的对照

**Pull，712000。** 两支从相同原生状态开始，改变抓持位置 35→105 mm。抬起后工具在 TCP 中 x 分别为 −29.80、−101.24 mm，均通过原生抓持检查。末态也均有抓持信号，但前者物体 x 移动 +1.33 mm、y 移动 +130.57 mm，后者 x 移动 −268.57 mm，最终目标距离 0.702→0.424 m，原生结果 0→1。不能将它解释为“只是是否抓住”。该例同时包含姿态漂移、接触和有限步数影响，不宣称单一原因。另有同抓持、不同后段方向的 **24 组前段状态完全一致**的配对检查。

**Charger，721000。** 两支都是 45° 抓持；第 81 步抬起后的记录 q、物体姿态和抓持变换相同，随后接近距离 50→75 mm。末态位置误差 22.05→3.66 mm，角度误差 0.00160→0.0660 rad，原生结果 0→1。前者在第 200 步仍处于 INSERT_3，后者完成 INSERT_5；接触力峰值 0→27.02 N。**这是后续参数影响规划/执行预算与实际插入的案例，不是证明更长接近距离普遍更好。** 原生成功条件为位置≤5 mm 且角度≤0.2 rad，未额外声称实机插接或长期稳定性。

## 学习机制与科学边界

- 两个决策边界：抓取前选择倾角；真实抬起并通过抓持检查后选择接近距离。前段失败不伪造后段样本。
- 54 维部署输入：关节 q/qvel、TCP、工具、目标、实测 TCP→工具变换、工具线/角速度、剩余步数及已选抓持倾角。使用仿真可见状态；没有未来标签。它并非包括控制器内部状态和全部接触状态的完整 Markov 状态。
- 每个边界一个 32 单元 tanh 网络；3 个离散动作，每动作输出成功价值及两个辅助量。三种模型架构、初始化种子、优化器、300 epoch/边界相同；共 1800 个优化步。真实训练得到的三组模型与归一化参数均保留。
- 普通 FQ：后段学习实际原生结果，前段回传实际到达状态上的 max 后段 Q；监督前段则学习采样后段参数下的实际平均结果。辅助 FQ 仅额外预测 `clip(1-position_error/0.005, -5, 1)` 和 `clip(1-angle_error/0.2, -5, 1)`，权重 0.2，不修改原生任务奖励/成功条件。
- 训练只有 18/108 正例。抬起后有效样本 104；36 个“初态×抓持角”组中有 3 组后段可用性不一致。回传使用每条实际到达状态，**不偷换成相同前段**。MPLib RRT 的随机性未被完全控制，不能把所有不同执行结果都归因于参数。
- 实测抓持变换本来就可由当前 TCP/物体姿态算出，不作为“新增后验信息”的创新。辅助目标是训练信号假设，结果不支持其当前实现。
- [STAP](https://github.com/agiachris/STAP) 已研究技能价值引导的组合；本轮通用 FQ 本身不是独立贡献。[Foresight Residual RL](https://arxiv.org/abs/2607.16506) 用视觉未来成功预测改善 VLA residual 的稀疏奖励；本轮是固定执行器的离散技能参数与实际物理裕量，未复现其完整算法，不能声称超越。[Grasp to Act](https://grasp2act.github.io/) 面向灵巧手动态工具操作的抓持优化与残差手指控制；本轮为双指夹爪、执行边界参数适应，权限与问题不同。

## 下一轮依据

保留 Charger 局部机会，先用有限的**重复同动作 / 保存完整仿真及控制器状态后的同边界分支**分离随机性和参数收益。候选信号应直接针对剩余步数、可达性、插入进度和接触下抓持稳定性，避免只回归终态距离；以固定强控制器为回退，检验动作选择是否既救回失败又避免 723002 一类退化。需要先证实这些信号能预测不同参数的相对效果，再训练或扩种子。若较强执行器消除差异，或剩余变化不可预测，则更换任务，不能维持一个没有方法空间的 benchmark。
